🗂️ Aula 20 — Comparação entre tabelas

📅 03/06/2026 ⏱ 50 minutos 🎯 Escola que Queremos 📚 Fundamentos de Estatística

🎯 O que vamos aprender?

Nesta aula de laboratório, vamos comparar duas tabelas e perceber diferenças entre categorias, concentrações e leituras possíveis. O foco é avançar da leitura de uma tabela isolada para a comparação entre conjuntos de dados.

💡 Aplicação no projeto: comparar grupos pesquisados no projeto.

🧪 Base de laboratório

Arquivo de apoio: dados_vacinacao_10col_50linhas.csv

Vamos usar duas tabelas construídas nas aulas anteriores a partir da base fictícia de vacinação. Depois, essa mesma lógica será aplicada às tabelas geradas com os dados do projeto Escola que Queremos.

Baixe a base: dados_vacinacao_10col_50linhas.csv

📘 Conteúdo principal

Conceito central: comparar tabelas é analisar diferenças e semelhanças entre conjuntos organizados de dados.

Quando comparamos duas tabelas, observamos quantas categorias cada uma possui, qual apresenta maior concentração em uma resposta, qual é mais variada e o que cada conjunto revela de diferente.

No projeto Escola que Queremos, essa habilidade será importante para comparar públicos, grupos, turmas e resultados, permitindo leituras mais completas da realidade escolar.

🧭 Roteiro guiado no laboratório

  1. Usar duas tabelas construídas nas aulas anteriores.
  2. Indicar qual tabela tem mais categorias.
  3. Indicar qual tabela mostra maior concentração em uma resposta.
  4. Explicar o que cada tabela revela de diferente.
  5. Escrever uma conclusão comparativa final.

✅ Microentrega

Produção esperada: comparação escrita entre duas tabelas, com conclusão final.

📝 Resumo para o Caderno — Comparação entre tabelas

  1. Comparar tabelas ajuda a perceber diferenças entre conjuntos de dados.
  2. Uma tabela pode ter mais categorias.
  3. Outra pode mostrar maior concentração em uma resposta.
  4. A comparação revela semelhanças e diferenças importantes.
  5. No projeto Escola que Queremos, comparar tabelas ajuda a entender melhor os públicos da escola.
  6. Comparar tabelas amplia a leitura estatística dos dados.
