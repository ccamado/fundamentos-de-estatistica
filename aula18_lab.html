📅 03/06/2026⏱ 50 minutos🎯 Escola que Queremos📚 Fundamentos de Estatística

🎯 Objetivo

Construir tabelas simples de frequência a partir da base fictícia de vacinação.

💡 Aplicação no projeto: construir tabelas com informações do projeto.

🧪 Base

Baixar CSV da aula

🧭 Roteiro

  1. Abrir a base CSV.
  2. Montar uma tabela de frequência para a coluna Vacina.
  3. Montar uma tabela de frequência para a coluna Bairro.
  4. Montar uma tabela de frequência para a coluna Retorno_30dias.
  5. Revisar a contagem final.

📝 Copia no caderno

  1. Construir tabela é organizar categorias e frequências.
  2. Primeiro identificamos as categorias.
  3. Depois contamos as ocorrências.
  4. Por fim organizamos em colunas.
