🗂️ Aula 19 — Interpretação de tabelas

📅 03/06/2026 ⏱ 50 minutos 🎯 Escola que Queremos 📚 Fundamentos de Estatística

🎯 O que vamos aprender?

Nesta aula de laboratório, vamos interpretar o que uma tabela revela sobre os dados observados. O foco é sair da simples organização e avançar para a leitura do que os resultados mostram.

💡 Aplicação no projeto: ler o que tabelas revelam sobre públicos diferentes da escola.

🧪 Base de laboratório

Arquivo de apoio: dados_vacinacao_10col_50linhas.csv

Vamos usar a base fictícia de vacinação e as tabelas construídas na aula anterior para treinar a leitura estatística. Depois, a mesma lógica será aplicada aos dados do projeto Escola que Queremos.

Baixe a base: dados_vacinacao_10col_50linhas.csv

📘 Conteúdo principal

Conceito central: interpretar tabela é explicar o que os números mostram e o que eles sugerem sobre a realidade observada.

Quando uma tabela já está pronta, o próximo passo é ler o que ela revela. Isso inclui perceber qual categoria apareceu mais, qual apareceu menos, se existe empate, se há concentração em uma resposta e que leitura geral pode ser feita.

No projeto Escola que Queremos, essa habilidade será importante para compreender melhor os públicos da escola e identificar padrões nas respostas coletadas.

🧭 Roteiro guiado no laboratório

  1. Usar uma tabela construída na aula anterior.
  2. Indicar a categoria que apareceu mais.
  3. Indicar a categoria que apareceu menos.
  4. Verificar se existe empate.
  5. Escrever o que a tabela revela sobre os dados observados.
  6. Apontar uma decisão prática que poderia nascer dessa leitura.

✅ Microentrega

Produção esperada: interpretação escrita de uma tabela, com pelo menos quatro respostas completas.

📝 Resumo para o Caderno — Interpretação de tabelas

  1. Interpretar tabela é explicar o que os números mostram.
  2. A tabela ajuda a enxergar padrões e frequências.
  3. Mais frequência indica maior ocorrência.
  4. Menor frequência indica menor ocorrência.
  5. Também devemos observar empates e concentrações.
  6. No projeto Escola que Queremos, interpretar tabelas ajuda a compreender melhor a escola.
